# EVALUATION

## Evaluation Goal

The evaluation is real end-to-end:

```text
Fortran source -> Flang HLFIR -> fiap-opt -> reports -> HLFIR/source transforms -> benchmark
```

Handwritten MLIR fixtures are optional regression tests only. The required project evidence uses real `.f90` inputs from `testcases/fortran/`.

## Main Command

```bash
./scripts/run.sh
```

Windows:

```powershell
scripts\run.ps1
```

This regenerates:

- `reports/hlfir/*.mlir` - HLFIR generated by Flang from real Fortran
- `reports/hlfir/*.json` - FIAP reports over generated HLFIR
- `reports/hlfir/summary.csv` - strict expected-classification evaluation summary
- `reports/hlfir/*.transformed.mlir` - post-transform HLFIR/FIR rewrite evidence
- `reports/hlfir/transforms.csv` - count of applied backend rewrites
- `reports/source/*.transformed.f90` - source rewrite evidence
- `reports/validation.csv` - generated MLIR/source validation evidence
- `reports/profile/generated_profile.csv` - generated profile-site evidence
- `reports/refinement/function_result.refined.json` - profile-guided refinement evidence
- `reports/benchmark/runtime.csv` - baseline vs optimized timing and output-equivalence checks

## Real Fortran Test Cases

| Source file | Construct | Expected primary classification | Why it matters |
| --- | --- | --- | --- |
| `vector_add.f90` | rank-1 array expression | `provably-eliminable` | Demonstrates the classic `a = b + c` hidden temporary |
| `matrix_stencil.f90` | 2D elemental expression | `provably-eliminable` | Demonstrates larger static byte estimates |
| `function_result.f90` | array-valued function result | `possibly-unnecessary` | Needs interprocedural/profile evidence |

| `escaping_temp.f90` | temporary passed to a call | `necessary` | Failure case: unsafe local rewrite is refused |
| `assumed_shape_kernel.f90` | assumed-shape descriptor expression | `necessary` | Dynamic descriptor/alias-sensitive case is refused |
| `saxpy_real_kernel.f90` | SAXPY-style vector update | `provably-eliminable` | Real-kernel-style repeated vector update |
| `laplace2d_real_kernel.f90` | Laplace-style 2D stencil update | `provably-eliminable` | Larger 2D expression with nested HLFIR elementals |
| `option_pricing_real_kernel.f90` | pricing-style vector expression | `provably-eliminable` | Expression with scalar intrinsics and array operands |
| `polybench_jacobi1d.f90` | PolyBench-style Jacobi update | `provably-eliminable` | Larger loop kernel with repeated elemental assignments |
| `rank3_tensor_update.f90` | rank-3 tensor expression | `provably-eliminable` | Confirms backend scalarization is not limited to rank 1/2 |
| `pointer_alias.f90` | pointer-backed array expression | `necessary` | Failure case: conservative alias evidence blocks unsafe rewrite |
| `strided_section_update.f90` | strided array section expression | `necessary` | Failure case: non-contiguous section rewrite is refused |

Strict Fortran-HLFIR evaluation command:

```powershell
python scripts\analyze_fortran_hlfir.py `
  --flang D:\llvm-project\build\bin\flang.exe `
  --tool build\fiap-opt.exe `
  --source-dir testcases\fortran `
  --out-dir reports\hlfir `
  --summary reports\hlfir\summary.csv `
  --strict
```

`--strict` fails if a known Fortran source misses its expected primary classification.

## Metrics

`reports/hlfir/summary.csv` contains:

- `source`
- `generated_hlfir`
- `report`
- `sarif`
- `sites`
- `provably_eliminable`
- `possibly_unnecessary`
- `necessary`
- `expected_primary_classification`
- `expected_met`
- `estimated_bytes`
- `estimated_removable_bytes`
- `estimated_reduction_percent`
- `constructs`

Each JSON/SARIF entry also includes source snippet, best-effort RHS expression snippet/range, rank, shape extents, estimated element count, element byte width, legality status, legality reason, typed-Flang match, shape evidence, and alias evidence.

The conservative static comparison is:

```text
optimized estimated bytes = baseline estimated bytes - provably eliminable estimated bytes
```

Only `provably-eliminable` bytes are counted as removable.

## HLFIR/FIR Transformation Evidence

The safe backend transform consumes real generated HLFIR:

```powershell
build\fiap-opt.exe reports\hlfir\vector_add.mlir --apply-transforms --print-annotated-ir
```

The generated files:

- `reports/hlfir/vector_add.transformed.mlir`
- `reports/hlfir/matrix_stencil.transformed.mlir`
- `reports/hlfir/saxpy_real_kernel.transformed.mlir`
- `reports/hlfir/laplace2d_real_kernel.transformed.mlir`
- `reports/hlfir/option_pricing_real_kernel.transformed.mlir`
- `reports/hlfir/polybench_jacobi1d.transformed.mlir`
- `reports/hlfir/rank3_tensor_update.transformed.mlir`
- `reports/hlfir/transforms.csv`

show `hlfir.elemental` assignments replaced by explicit `fir.do_loop` nests. The transform remains conservative: escaping temporaries, pointer-alias-sensitive expressions, and heap-required allocatable storage are not rewritten.

The regression evidence gate is:

```powershell
python scripts\check_pipeline_outputs.py --reports-dir reports --require-benchmark
```

It verifies required Fortran inputs, expected classifications, eliminated backend elementals, validation status, profile refinement, and benchmark output equivalence.

## Source Transformation Evidence

The safe auto-transform consumes real generated reports:

```powershell
python src\fiap_source_transformer.py `
  --report reports\hlfir\vector_add.json `
  --source testcases\fortran\vector_add.f90 `
  --output reports\source\vector_add.transformed.f90
```

It rewrites `a = b + c` into a `do concurrent` loop.

The full pipeline also writes:

- transformed source files for every input in `testcases/fortran/`

Notable source rewrites include:

- explicit loop nests for array expressions
- allocatable shape guards for `allocatable_update.f90`
- function-result result-buffer conversion for `function_result.f90`

## Profile-Guided Refinement Evidence

The refinement also consumes a real generated HLFIR report:

```powershell
python scripts\refine_profile.py `
  --report reports\hlfir\function_result.json `
  --profile reports\profile\generated_profile.csv `
  --out reports\refinement\function_result.refined.json
```

This upgrades the function-result site when profile data proves stable runtime shape.

Profile sites can also be shown directly:

```powershell
build\fiap-opt.exe reports\hlfir\function_result.mlir --emit-profile-sites
```

## Failure Case

Show:

```powershell
build\fiap-opt.exe reports\hlfir\escaping_temp.mlir --format=text
```

Expected:

- classification: `necessary`
- transform: `none`
- reason: the temporary escapes the local statement/procedure

This proves FIAP is conservative and does not blindly rewrite every temporary.
