# FIAP End-To-End Presentation Guide

Use this order. Do not lead with the MLIR fixtures.

## 1. Show Real Input Files

Open:

- `testcases\fortran\vector_add.f90`
- `testcases\fortran\matrix_stencil.f90`
- `testcases\fortran\function_result.f90`
- `testcases\fortran\allocatable_update.f90`
- `testcases\fortran\escaping_temp.f90`

Say:

> These are the five required test cases, and they are real Fortran source files. The pipeline starts from these `.f90` files.

## 2. Run The Real Pipeline

Run:

```powershell
scripts\run.ps1
```

Say:

> This command asks Flang to emit HLFIR from the Fortran files, then runs FIAP on the generated HLFIR, then writes reports, transformation output, profile refinement output, and benchmark output.

## 3. Show Generated HLFIR

Open:

- `reports\hlfir\vector_add.mlir`
- `reports\hlfir\escaping_temp.mlir`

Say:

> These files were generated by Flang. They are not handwritten mock MLIR.

## 4. Show FIAP Reports

Open:

- `reports\hlfir\vector_add.json`
- `reports\hlfir\escaping_temp.json`
- `reports\hlfir\summary.csv`

Say:

> FIAP analyzes the generated HLFIR and maps allocation sites back to Fortran source lines.

## 5. Show The Safe Optimization

Run:

```powershell
build\fiap-opt.exe reports\hlfir\vector_add.mlir --format=text
type reports\source\vector_add.transformed.f90
```

Say:

> `vector_add.f90` has a provably eliminable array temporary. FIAP rewrites `a = b + c` into a `do concurrent` loop.

## 6. Show The Failure Case

Run:

```powershell
build\fiap-opt.exe reports\hlfir\escaping_temp.mlir --format=text
```

Say:

> This is the failure case. The temporary is passed into another procedure, so FIAP marks it necessary and refuses a local rewrite.

## 7. Show Function Result And Profile Refinement

Open:

- `reports\hlfir\function_result.json`
- `reports\refinement\function_result.refined.json`

Say:

> Static analysis marks the array-valued function result as possibly unnecessary. Profile evidence can upgrade the site when shape is stable.

## 8. Show Baseline Comparison

Open:

- `reports\benchmark\runtime.csv`
- `EVALUATION.md`

Say:

> The project reports static allocation reduction and runtime baseline-vs-optimized measurements. Runtime is noisy for small kernels, so the primary deterministic metric is allocation reduction from HLFIR evidence.

## One-Line Summary

> FIAP starts from real Fortran source, uses Flang to generate HLFIR, builds an Allocation Provenance Graph, classifies hidden allocation sites, reports source-mapped evidence, safely rewrites simple eliminable cases, and refuses unsafe escaping temporaries.
